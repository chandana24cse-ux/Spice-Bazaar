# Spice-Bazaar
Spice Bazaar – AI-Powered Spice Marketplace

Spice Bazaar is a web-based marketplace designed to connect spice farmers and sellers directly with buyers through a simple, user-friendly platform. The project aims to make spice trading more accessible by helping users explore spice products and simplifying the buying and selling process.

Key Features

- User-Friendly Interface: Simple and accessible design for browsing spice products.
- Spice Marketplace: Displays spice products and relevant product information.
- Shopping Cart: Allows users to manage products they wish to purchase.
- Farmer-to-Buyer Connection: Supports a more direct marketplace experience.
- Web-Based Platform: Built using web technologies for easy access through a browser.

Technologies Used

- HTML and CSS for the user interface and styling.
- JavaScript for interactive frontend functionality.
- PHP for server-side processing.
- MySQL for database management.
